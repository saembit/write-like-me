# write-like-me

This repo is a Claude Code plugin (and a portable skill for Codex, opencode, etc.) that captures how a person writes so agents can match it. The skill itself lives in skills/write-like-me/SKILL.md, read that first to understand what the thing does.

Before writing or editing anything here read SUMMARY.md if it exists, it's the brief for this project. If WRITING-STYLE.md exists in the repo root, follow it for all prose (README, SKILL text, comments, commit messages). WRITING-SAMPLE.txt has the raw samples it was built from. These three files are local only and not tracked in git.

The voice for this repo is mine with AI help, not AI by itself. Plain, short, first person, no em dashes, no emoji, no marketing tone. Small rough edges are fine. It should read like I wrote it and had Claude help tighten it, not like Claude wrote it and I signed off.
